# Публикация SmartSchedule в интернете

## Что получится
После публикации будет одна ссылка, которую можно отправить учителю. Устройства могут быть в разных Wi‑Fi. Все работают с одной PostgreSQL-базой.

## 1. Создать PostgreSQL
Подойдёт Supabase Free для учебного/демонстрационного проекта: он включает PostgreSQL и 500 MB базы. Free-проекты могут приостанавливаться после периода бездействия, поэтому это вариант для демонстрации, а не гарантия постоянной доступности.

## 2. Загрузить проект в GitHub
Создай новый репозиторий и загрузи все файлы этой папки.

## 3. Создать Web Service
На Render создай Web Service из репозитория.
Build Command:
    pip install -r requirements.txt
Start Command:
    gunicorn app:app --workers 1 --threads 4 --timeout 120
Health Check Path:
    /health

## 4. Переменные
Добавь:
SMARTSCHEDULE_SECRET — длинная случайная строка.
DATABASE_URL — connection string PostgreSQL.

## 5. Получить ссылку
После успешного deploy Render выдаст адрес вида https://имя.onrender.com.
Его можно отправить учителю. При изменении данных запись идёт в центральную БД, а открытые страницы проверяют ревизию и обновляются.

## Важно
Не публикуй DATABASE_URL в GitHub и не вставляй его в исходный код.

Для полностью бесплатного учебного варианта есть ограничения: Render Free может «засыпать» после 15 минут без запросов, а Supabase Free может приостанавливать неактивные проекты. Перед реальной эксплуатацией школы нужен постоянный тариф/сервер, резервное копирование и полноценная авторизация.
