# SmartSchedule — центральный сервер

Эта сборка предназначена для двух режимов:

1. **Локально на Windows** — SQLite, `START.bat`.
2. **Через интернет** — Flask/Gunicorn + PostgreSQL через `DATABASE_URL`.

В интернете все пользователи читают и изменяют одну центральную базу. Открытые страницы проверяют номер ревизии и автоматически обновляются после изменений.

## Качество расписания
Генератор оптимизирует не только отсутствие окон, но и нагрузку:
- цель: 0 окон;
- допустимый максимум: 1 окно;
- максимум 2 сложных предмета уровня 3 в день;
- максимум 2 тяжёлых предмета подряд;
- максимум 12 баллов нагрузки в день по умолчанию (1/2/3 за предмет);
- не допускаются одновременные занятия одного учителя или кабинета;
- если ограничения несовместимы, результат помечается «ТРЕБУЕТ ПРОВЕРКИ» и показывает неразмещённые уроки.

## Публичный сервер
Сборка готова к запуску командой:
`gunicorn app:app --workers 1 --threads 4 --timeout 120`

Нужно задать:
- `DATABASE_URL`
- `SMARTSCHEDULE_SECRET`

Не хранить секреты в GitHub.

## Важно о бесплатных сервисах
Бесплатный Render подходит для теста, но web-сервис может засыпать после 15 минут без входящих запросов. Локальная файловая система бесплатного web-сервиса не является постоянным хранилищем. Поэтому для общей базы используется внешняя PostgreSQL, а не `school.json`.

Free PostgreSQL в Render сейчас ограничен и имеет срок жизни 30 дней, поэтому в инструкции предложен внешний PostgreSQL-провайдер для учебной демонстрации.

### Совмещённые уроки
По умолчанию один учитель **не может вести два класса одновременно**. Чтобы разрешить это исключение, у предмета заполните поле **«Совмещённые классы (через запятую)»**, например `5А, 5Б`. Тогда SmartSchedule может поставить один и тот же предмет и одного учителя одновременно этим классам. Для других классов такое совмещение не разрешается.

## Роли пользователей
При входе выбирается режим: **Составитель расписания** или **Учитель**. Учитель выбирает свою фамилию и получает только просмотр расписания и изменение кабинета собственных уроков. Составитель получает полный доступ к настройкам и генерации.


## Уведомления и сокращения
В браузере можно включить уведомления об изменении общей ревизии расписания. Пока SmartSchedule открыт в браузере, при изменении данных появляется системное уведомление, а страница синхронизируется. Для настоящих push-уведомлений при полностью закрытом браузере потребуется подключение Web Push/VAPID при публикации. В расписании и Excel «Спортивный зал» отображается как «с/з».
